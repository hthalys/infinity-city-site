# 🌆 Infinity City RP

## 🚀 Sobre o Projeto

Bem-vindo ao repositório oficial do site da **Infinity City RP**.

A Infinity City RP é um projeto focado em trazer uma experiência completa de **RolePlay para SA-MP Mobile**, criando uma comunidade moderna, organizada e com sistemas pensados para proporcionar diversão, imersão e interação entre os jogadores.

Este repositório contém o código do site oficial da Infinity City RP, desenvolvido para apresentar o servidor, divulgar novidades, disponibilizar informações importantes e facilitar o acesso dos jogadores ao projeto.

---

## ✨ Recursos do Site

✅ Página inicial moderna e responsiva  
✅ Sistema de notícias e atualizações  
✅ Área de regras do servidor  
✅ Página de download do Launcher  
✅ Links oficiais da comunidade  
✅ Integração com Discord e Instagram  
✅ Aviso de cookies  
✅ Design otimizado para computador e dispositivos móveis

## 🎮 Sobre a Infinity City RP

A Infinity City RP busca criar um ambiente de RolePlay onde os jogadores possam construir histórias, participar de organizações, explorar oportunidades e fazer parte de uma comunidade ativa.

Nosso objetivo é oferecer:

🌎 Uma cidade viva e dinâmica  
👮 Organizações e sistemas de RolePlay  
💼 Economia e empregos  
🏠 Propriedades e veículos  
📱 Experiência otimizada para Mobile
